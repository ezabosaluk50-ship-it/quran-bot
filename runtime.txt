# Quran Bot

بوت قرآن كريم يعمل على تيليجرام  
يتيح لك:

- اختيار القارئ
- اختيار السورة
- سورة عشوائية
- قارئك المفضل
- البحث عن سورة
- تقسيم السور إلى صفحتين
- تشغيل مباشر بدون تحميل

## التشغيل

1. ضع التوكن داخل bot.py
2. ثبّت المكتبات:

pip install -r requirements.txt

3. شغّل البوت:

python bot.py
